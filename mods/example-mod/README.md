# example-mod —— 示例 Mod（教学）

这是一个**可以直接抄**的样板 Mod：它把「Mod 能做什么」全部演示了一遍，而且**不影响原版内容**。
想读文档：应用里的 **Mod 管理页 → `📖 Mod 制作文档`**（`/mods/docs`）与 **`📘 gameAPI 参考`**（`/mods/api`）。

- 默认**禁用**（教学用；不该悄悄改变所有人的游戏数据）。想试就在 Mod 管理页启用它，或点「查看数据 →」看它装了什么。

## 这个目录里每个文件在教什么

| 文件 | 演示的内容 |
|------|-----------|
| `manifest.json` | 必填字段（`name` / `version`）、`permissions`、**`dependencies`**（为什么必须依赖 `lifeRestart-data`，见下）、`targets` / `deterministic` 这类可选字段 |
| `talents.json` | 天赋表的字段：`effect`（属性效果）与 `condition`（**触发时**才判定的门槛，不是入池条件） |
| `events.json` | 事件表的字段：`event`（正文，注意字段名不叫 description）、`effect`、`include` / `exclude`（能否随机触发）、`branch`（**顺序**匹配的条件分支）、`postEvent`（后续文本）、`NoRandom`（禁止随机触发，只能被 branch 链到） |
| `achievements.json` | 成就表的字段：`condition` + `opportunity`（在哪个时机判定：START / TRAJECTORY / SUMMARY / END）+ `hide` |
| `age.json` | 年龄表怎么"加事件"，以及最容易踩的坑：**age 是整键替换，不是追加** |
| `code.js` | 代码入口：能力探测、`param.define` 注册新参数、4 个钩子、**改真实游戏属性**（`property.change`，20 岁精神 +3）、**观察属性变化**（`propertyChange` + 用 `source` 过滤自己造成的噪声）、运行时增删数据、随包依赖 `require()`、宿主桥降级 |

## 两个必须知道的坑（本示例刻意踩了一遍）

**1. `age.json` 是整键替换。** 示例里 `"1"` 这一岁写成：

```json
{ "1": { "age": "1", "event": [["90001", 20], ["10009", 10], ["10010", 10], ["10011", 1]] } }
```

`10009` / `10010` / `10011` 是原版数据里 age 1 的三个事件 —— **必须自己抄一遍**，否则启用本 Mod 后
"你从小生活在农村/城市/美国国籍"这三句就再也不会出现了（因为这一岁的整张列表被替换掉了）。
抄了它们的 id 但**没**提供事件定义时不会崩：引擎对找不到的事件是 `try/catch + warn 跳过`
（日志里会出现 `doEvent: 事件缺失或异常（[ERROR] No Event[10009]），跳过`），但那一岁会少几句。

**2. 加载顺序 = 依赖顺序，后加载覆盖先加载。** 所以想"补充原版内容"的 Mod **必须声明
`"dependencies": ["lifeRestart-data"]`**：否则它会排在数据 Mod 前面，`age.json` 里的替换会被
数据 Mod 整键覆盖掉 —— 表现是"我的事件从来不触发"，而日志里什么都看不出来。
（若数据 Mod 被禁用/完全移除，依赖会记一条 `缺失依赖: lifeRestart-data`，本 Mod 仍会加载。）

## 启用后能观察到什么

- 抽卡时天赋池里多出「示例·锦鲤」（钩子塞进去的）；「示例·大器晚成」30 岁后才生效
- 1 岁时多出一句「【示例事件】你在路边捡到一枚硬币。」（age 表），并按 `branch` 顺序走后续：
  有钱（`MNY > 8`）→ 许愿池；否则 → 古币被收走
- 每 10 岁轨迹里多一句「【示例 Mod】你 N 岁了，示例幸运值 N」（`onYearAdvance` + 自定义参数）
- 带「示例事件」字样的文本会被加上 ✨ 前缀（`onEventRender` 是唯一返回值生效的钩子）
- 成就「示例·活到十岁」会在总结/结束时判定
- 日志里能看到能力探测与降级信息（没有后端时那段代码被安全跳过）

## 自己做一个

1. 复制本目录 → 改名 → 改 `manifest.json` 的 `name`（**目录名与 name 建议一致**，页面按目录名寻址）
2. 删掉不需要的表，只留你真正要用的
3. 在 Mod 管理页 `+ 安装 Mod（.zip）` 上传打包好的 zip，或 `⬇ 从 GitHub 安装` 直接从仓库装
4. 出问题先看设置页的**日志面板**（日志级别调到 `debug`/`trace`），再看「查看数据 →」确认表真的进来了
